## 1. 这个项目挑平台的四个硬条件

不是所有「免费托管」都能跑，先看清约束，避免传上去接口全 500：

| 条件 | 原因 | 被淘汰的平台 |
| --- | --- | --- |
| ① 常驻 Node 进程 | Express 监听端口，`/api/*` 是后端接口 | GitHub Pages、Netlify、Cloudflare Pages、Vercel 静态托管 —— 页面能开、功能全废 |
| ② 文件系统可写 | 收藏 / 新建 / 导入会写 `data/contacts.json` | Vercel、Cloudflare Workers 等纯 Serverless（项目磁盘只读，只有 `/tmp` 可写） |
| ③ 公网非 localhost | 原帖明确 `A localhost link does not count` | 本机 `npm start`、内网穿透（严格说也不算云服务器） |
| ④ 国内能打开 | 老师/助教要能点开链接验收 | `*.vercel.app`（大陆无 CDN 节点、部分地区 DNS 污染）、部分海外小众 PaaS |

**好消息**：项目本身已为云部署准备好，无需任何改造 ——
`server/config.js` 读 `process.env.PORT`（Render / Railway 会自动注入）、`HOST` 默认 `0.0.0.0`，`package.json` 有 `start` 脚本，`engines.node >= 18`。

## 4. 方案 A：Render 免费 Web Service（详细步骤）

### 4.1 为什么它最合适

- 免费层**不需要绑信用卡**，注册只要 GitHub 账号
- 常驻 Node 进程、文件系统可写 → 收藏 / Excel 导入导出**真的能用**（不像 Vercel 要改代码）
- 自动注入 `PORT`，项目已兼容；每次 `git push` 自动重新部署
- 唯一代价：15 分钟没人访问会休眠，首次打开要等约 1 分钟；休眠后本地改动的数据回到仓库里的 10 条演示数据

### 4.2 前置：先把代码推上 GitHub

本机没有系统 `git` / `npm`，用已装好的 **GitHub Desktop**，按 `docs/GitHub上传详细流程.md` 完成 3 次提交并 `Publish repository`。
确认仓库网页上能看到 `package.json`、`server/`、`public/`、`data/contacts.json`、`render.yaml`（可选，见 4.4）。
**仓库必须是 Public**，Render 免费层导入私有仓库也能跑，但作业要求 Public。

### 4.3 网页部署（方式一：手填，最直观）

1. 打开 <https://render.com/> → **Get Started / Sign Up** → 选 **Sign in with GitHub**，授权
2. 控制台右上角 **New +** → **Web Service**
3. **Connect a repository** → 找到 `address-book` → **Connect**（若列表为空，点 *Configure account* 给 Render 授权该仓库）
4. 逐项填写（**这几项是关键，填错会 404 或启动失败**）：

   | 字段 | 填什么 | 为什么 |
   | --- | --- | --- |
   | Name | `ee308fz-address-book` | 会变成链接前缀 |
   | Region | `Singapore` / `Oregon` 均可 | 新加坡对国内稍好 |
   | Branch | `main` | 默认分支 |
   | Root Directory | **留空** | 项目就在仓库根目录 |
   | Runtime | `Node` | 不要选 Docker / Static Site |
   | Build Command | `npm install` | 安装 express / exceljs / multer |
   | Start Command | `npm start` | 等价于 `node server/index.js` |
   | Instance Type | **Free** | 选错会要付费 |

5. 展开 **Advanced / Environment Variables**，添加（可选但推荐）：

   | Key | Value |
   | --- | --- |
   | `NODE_VERSION` | `22` |
   | `HOST` | `0.0.0.0` |

   `PORT` **不要手动设置** —— Render 自动注入，项目会读取它。
6. **Health Check Path** 填 `/api/health`（有这个字段就填，用于部署健康检查）
7. 点 **Create Web Service** → 看 Logs，出现 `EE308FZ 通讯录 · Address Book` 且状态变 **Live** 即成功
8. 复制顶部链接，形如 `https://ee308fz-address-book.onrender.com`

### 4.4 方式二：用项目自带的 `render.yaml` 一键蓝图（可选）

仓库根目录已放 `render.yaml`，内容与上表一致。若想省掉手填：
控制台 **New + → Blueprint** → 选仓库 → Render 会自动读出配置 → 确认 **Free** 计划 → **Apply**。
⚠️ 两种方式**任选其一，不要同时建两个服务**，否则会多占免费实例小时。

### 4.6 必须如实知道的两个限制

- **数据不持久**：免费层文件系统是临时的，服务休眠、重启、重新部署后，`data/contacts.json` 会回到仓库里的 10 条演示数据。演示视频请**一次连续录完**；博客里可以说明「免费层使用临时文件系统，重启恢复演示数据」，这是诚实的技术说明，不是缺陷掩饰。
- **会休眠**：15 分钟无请求后首次访问要等约 1 分钟，Render 会显示加载页。老师点开可能需要刷新一次。想彻底避免只能升级付费计划或改用方案 B 的 ECS。

### 4.7 排错速查

| 现象 | 原因 / 处理 |
| --- | --- |
| 首页 404、接口全 404 | Runtime 选成了 Static Site；或 Root Directory 填错 → 改回 `Node` + 留空 |
| 启动时 `Cannot find module express` | Build Command 漏了 → 填 `npm install` |
| 一直 `Deploy failed` / 端口相关 | Start Command 必须是 `npm start`；不要写死 `PORT=3000` |
| 页面能开但点收藏报 500 | 检查 Logs 是否 `EACCES`；正常情况免费层文件可写，多为部署未完成 |
| `Application failed to respond` | 健康检查路径填错 → `/api/health` |
| 第一次打开转圈很久 | 免费层冷启动，等约 1 分钟，属正常 |
| 数据第二天变回 10 条 | 休眠重置，见 4.6 |
| `*.onrender.com` 国内打不开 | 换新加坡区域重试；仍不行就主用已发布链接 / 方案 B，把 Render 作为备用链接 |

### 4.8 国内访问优先的备选：Zeabur

Zeabur 是国内团队的 PaaS，亚太节点（东京/新加坡/中国香港）对国内直连更友好，支持 Git 导入 Node 服务、有免费计划（会自动休眠，政策变动较快）。若 Render 链接在手机上打不开，可按同样字段在 <https://zeabur.com> 再部署一份。以官网当日免费政策为准。

## 5. 方案 B：国内免费 ECS（最贴题、加分最稳）

原帖写的是 `Deploy ... on a cloud server, such as Huawei Cloud or Alibaba Cloud`。**真 ECS 最贴这个口径**，而且能给博客补服务器配置、公网 IP、安全组、PM2 进程截图。

### 5.1 官方口径核实（2026-11-16 实测官网）

打开 `https://university.aliyun.com/`，活动名为 **「云工开物 · 阿里云高校用云支持计划」**，「我是学生」页规则原文要点：

⚠️ **纠正常见误传**：网上教程常写「学生认证直接送 1核2G 免费 12 个月 ECS」「99 元/年学生机」「90 天免费 ECS」，这些口径彼此矛盾且多为第三方营销文。官方给的是**优惠券，不是直接发一台免费服务器**。正确姿势是：认证 → 领 300 元券 → 在学生权益专区挑一台总价不超过券额的 ECS / 轻量应用服务器 → 用券抵扣到**应付 0 元**。免费多久取决于所选规格与时长，下单页会写清楚。

### 5.2 到底方便快捷吗

**顺利的话 15–30 分钟能开出机器**：全程网页操作，本机不用装 Git / Node / SSH 客户端（用控制台 Workbench 远程登录）；学信网自动校验通常 1–5 分钟，实例创建 1–3 分钟。

但比 Render（约 10 分钟、零认证）**慢且不确定**，五个卡点：

| 卡点 | 说明 | 今晚怎么办 |
| --- | --- | --- |
| 个人实名认证 | 必须先用支付宝/人脸完成，未实名无法领券 | 支付宝扫码，几分钟 |
| 学信网学籍 | 查不到或信息不一致会转人工审核 1–3 工作日 | 今晚赶不上就放弃，走 Render |

| 券只抵部分规格 | 选了不在适用列表的 ECS，支付页不抵扣 | 只在「学生权益专区」里挑，确认应付 0 元再提交 |

### 5.5 拿到机器后：直接用现成指南部署，零代码改动

最短命令集（完整版与 Nginx 反代见 `docs/云部署指南.md` 第 1–5 节）：

```bash
# SSH 登录（本机可用阿里云控制台的 Workbench，无需装 SSH 客户端）
ssh root@<公网IP>

# 1) 装 Node 22
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc && nvm install 22 && node -v

# 2) 拉代码（先按 docs/GitHub上传详细流程.md 把仓库传上去）
apt update && apt install -y git
git clone https://github.com/<你的用户名>/address-book.git
cd address-book

# 3) 装依赖
npm install --omit=dev --registry=https://registry.npmmirror.com

# 4) PM2 常驻（关掉 SSH 也不会停）
npm i -g pm2
PORT=3000 HOST=0.0.0.0 pm2 start server/index.js --name address-book
pm2 save && pm2 startup
```

浏览器打开 `http://<公网IP>:3000` 验证；想去掉端口号就按指南第 5 节配 Nginx 反代到 80。

#### 5.9.2 选哪一台

| 优先级 | 选什么 | 理由 |

| ① 首选 | 「包年包月不焦虑 → 云服务器」里 **2核2G 的 ECS 包年包月**，时长选 1 年（约 ¥284，被 300 元券全额抵扣） | 本项目 1核2G 就够（Node + Express + ExcelJS，10 条演示数据），2核2G 有富余；标准 ECS 有公网 IP + 安全组 + SSH，最贴原帖 `cloud server` 口径，博客截图最完整 |

1. **网络 / 公网 IP**：勾选 **「分配公网 IPv4」** —— 不勾的话老师打不开，这是唯一必须要手动开的项

## 6. 方案 C：Oracle Cloud Always Free（长期项目再考虑）

永久免费、真 VPS、200 GB 块存储、10 TB/月出站，规格在免费层里最豪横。但对**明晚就截止的作业**不划算：

- 必须绑定**实体 Visa / Mastercard / Amex 信用卡**（虚拟卡、预付卡、银联单币卡不行），有约 1 美元预授权
- 注册风控严：IP 属地、账单地址、持卡人姓名必须一致，全程关代理
- **Home Region 注册后不可更改**；ARM 实例常报 `Out of host capacity`，免费账号很难抢到
- 连续 7 天 CPU 过低可能被判定闲置并回收
- 海外节点，国内访问延迟明显高于国内 ECS

真要走：入口 `https://www.oracle.com/cloud/free/` → 选 Ubuntu 22.04 + `VM.Standard.A1.Flex` → 保存好 SSH 私钥 → 安全列表放行 80/3000 → 之后按第 5.5 节同样命令部署。
