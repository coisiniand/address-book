## 3. 功能实现细节（写"实现设计"章节时用这些素材）

### 3.1 收藏联系人（25 分）
- 数据模型为联系人增加 `bookmarked` 布尔字段，切换走 `PATCH /api/contacts/:id/bookmark`，不传值时自动取反。
- 前端侧栏有「我的收藏」独立入口与实时计数；卡片星标 + 「已收藏」徽标；排序支持"收藏优先"；支持勾选多人批量收藏。
- 收藏状态写入 Excel 的「收藏」列（`是`/`否`），导入兼容 `是/否/true/1/Y/★`，导出再导入不丢状态。

### 3.2 多种联系方式（10 分）
- `contactMethods` 是数组，元素 `{ id, type, label, value, primary }`，类型覆盖手机、座机、邮箱、微信、QQ、微博、领英、社交账号、地址、网站、其他共 11 类。
- 新建/编辑表单可动态增删联系方式行、指定"主要"；详情页按类型显示图标并支持一键复制；搜索会把所有联系方式的值拼进检索文本（输入手机号也能查到人）。
- 后端对类型白名单校验并对"主要"数量归一化，避免脏数据。

### 3.3 Excel 导入导出（25 分）
- 导出：**每人一行、每类一列**。姓名、收藏、公司、部门、职位、生日、标签、备注各占一列；联系方式按类型分列，同类型多条自动生成 `手机`、`手机2`、`邮箱2` 等列，列数按数据动态扩展；附「字段说明」工作表，冻结表头、自动筛选、隔行底色；支持"导出当前筛选结果"。
- 导入：三步式「上传解析（只解析不写库）→ 前端预览 → 选择重复策略 → 确认写入」，避免误操作污染数据。
- 兼容：中文/英文表头别名、带序号列名、`联系方式` 混合列（自动判断邮箱/手机/网址）；缺「姓名」列或旧版 `.xls` 明确报错；未识别列安全忽略并在预览中提示。
- 重复策略：`append` 全部新增、`merge` 按姓名合并并去重联系方式、`skip` 跳过同名。
- 往返一致性：导出的文件可直接再导入，收藏与多条联系方式不丢，已写入自动化测试。
